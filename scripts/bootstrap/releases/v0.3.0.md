Le dépôt devient une chaîne de livraison outillée, prête à recevoir le code du POC.

## Pipelines GitHub Actions
- **CI** : titre de PR conventionnel, actionlint, gitleaks, Trivy (SCA bloquant + IaC vers l'onglet Security), Dependency Review, build et tests Maven avec JaCoCo (seuil 80 %), SonarQube Cloud, image Docker + scan Trivy + SBOM, publication GHCR, job agrégé « Résultat CI » exigé par la protection de branche.
- **CodeQL** : SAST Java et analyse de sécurité des workflows.
- **CD staging** : cluster Kubernetes éphémère (kind), déploiement Kustomize, smoke tests, DAST OWASP ZAP.
- **Release** : images versionnées avec provenance et SBOM, documentation jointe, production soumise à approbation.

## Sécurité de la chaîne d'approvisionnement
- Correction de la CI rouge depuis le 10/10 : `trivy-action@0.24.0` n'existe plus depuis la compromission de mars 2026 (GHSA-69fq-xp46-6x23).
- Toutes les actions tierces sont épinglées par SHA de commit ; Dependabot surveille actions, Maven et images.

## Gouvernance
- Modèle de branches, Conventional Commits, SemVer, modèles d'issues et de PR, CODEOWNERS, `SECURITY.md`.
- Labels, jalons J0 à J5, kanban, environnements `staging` et `production`, protection de `main` et `develop`.
