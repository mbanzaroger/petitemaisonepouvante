Exigences de petitemaisonepouvante.com couvertes (US13 à US17), sur la base de v1.3.0.

## Nouveautés
| Sujet | Contenu | Où |
|---|---|---|
| Recommandations | « Recommandé pour vous » et « Vous aimerez aussi » selon les recherches, consultations et achats, raison affichée ; consentement dans « Mon espace », désactivé par défaut | US13, `docs/13` §9 |
| Gamme Evil Ed | Produits « Exclusivité Evil Ed », filtre du catalogue, mise en avant | `services/catalog-service` |
| Notifications selon la navigation | Nouvelles annonces dans les catégories consultées souvent, avec accord du membre | US14 |
| Actualités | Actualités et articles de fond ouverts à tous ; page « Rédaction » (ADMIN) | US15, `services/editorial-service` |
| Fanzine numérique | Extrait gratuit, achat à l'unité, liseuse intégrée (une page à la fois, sommaire, flèches du clavier, reprise de lecture), « Ma bibliothèque » ; droit vérifié à chaque page | US16, ADR-006 |
| Abonnement | Numérique ou papier et numérique, renouvellement dans les 60 jours, liste d'expédition (ADMIN), adresse effacée 90 jours après l'échéance | US17, `docs/13` §10 |
| Architecture | Hébergement en Europe ; feuille de route : enchères et diffusion des productions Evil Ed (v2), projections du festival (v3) | ADR-006 |

## Qualité
- editorial-service : 27 tests dont 13 d'intégration (PostgreSQL réel), couverture ≥ 80 %.
- Site : 139 tests Vitest ; parcours Playwright + axe des actualités, de la liseuse, de l'abonnement et de la rédaction.
- Staging (CD de main du 19/11/2026) : 35 contrôles de fumée, 14 scénarios Cucumber, 18 parcours Playwright, Lighthouse, supervision (7 cibles, 7 alertes, 22 panneaux), DAST ZAP sans échec.
- Chaîne : exception datée V-28 (nginx 1.30.6, jusqu'au 26/11/2026), faux positif ZAP qualifié V-29, construction Maven résistante aux refus de Maven Central.

## Mise à jour d'un environnement local existant
```bash
git pull && bash infra/init-env.sh      # ajoute EDITORIAL_DB_PASSWORD sans toucher aux autres valeurs
cd infra && docker compose --profile app up -d --build
```
