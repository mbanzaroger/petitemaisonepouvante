Espace communautaire demandé par le contexte (US8 à US12), sur la base de v1.2.0.

## Nouveautés
| Sujet | Contenu | Où |
|---|---|---|
| Troc et dons | Annonces publiques filtrables, publication, retrait, proposition d'échange ou demande de don, acceptation, refus, annulation | `services/community-service`, `frontend/src/pages/communaute` |
| Discussions | Conversation privée entre les deux membres d'une proposition ; salons thématiques entre passionnés ; anti-flood (5 messages / 10 s) | ADR-005 |
| Mon espace | Notifications (pastille dans l'en-tête), préférences, objets recherchés avec alerte à la publication, mes annonces | `frontend/src/pages/MonEspacePage.tsx` |
| Modération | Signalement par les membres, page « Modération » (ADMIN) : masquer ou rejeter ; alerte `ModerationEnAttente` | `docs/12`, `docs/13` §8 |
| Plateforme | Nouveau service et base dédiée, routes Gateway par niveau d'accès, NetworkPolicies, supervision | ADR-004, `k8s/` |
| Site | Compte connecté et profil visibles dans l'en-tête, refus de commande expliqués, diagnostic local (`infra/diagnostic.sh`), mode Codespaces | #109 |

## Qualité
- community-service : 41 tests dont 25 d'intégration (PostgreSQL réel), couverture ≥ 80 %.
- Site : 125 tests Vitest (couverture lignes 98 %), parcours Playwright + axe du troc complet, du salon et de la modération.
- Staging : contrôles de fumée US8 à US12, scénarios Cucumber, Lighthouse sur « Troc et dons ».

## Mise à jour d'un environnement local existant
```bash
git pull && bash infra/init-env.sh      # ajoute COMMUNITY_DB_PASSWORD sans toucher aux autres valeurs
cd infra && docker compose --profile app up -d --build
```
