Demandes de la recette du 19/11/2026 (US18 à US20), sur la base de v1.4.1.

## Nouveautés
| Sujet | Contenu | Où |
|---|---|---|
| Produits et stock | Création d'un produit avec son stock initial, modification, retrait de la vente et remise en vente, réapprovisionnement ligne par ligne | `/admin/stock`, `/admin/produits/nouveau`, `catalog-service`, `stock-service` |
| Commandes clients | Commandes de tous les clients (client, articles, total, statut), filtre par statut, synthèse et chiffre d'affaires confirmé | `/admin/commandes`, `order-service` |
| Inscription | « Créer un compte » (en-tête, panier, pages réservées) ; formulaire Keycloak en français, rôle client attribué d'office, politique de mot de passe | `infra/keycloak`, `k8s/platform` |
| Sécurité | Rôle `ADMIN` exigé au Gateway (routes `catalog-admin`, `orders-admin`) et dans les services ; écritures journalisées avec leur auteur ; analyse ciblée | `docs/13` §11 |

## Qualité
- Tests d'intégration du catalogue, du stock et des commandes (PostgreSQL réel) ; 150 tests Vitest.
- Staging : 9 contrôles de fumée (produit créé, approvisionné, commandé, suivi puis retiré ; formulaire d'inscription), 2 scénarios Cucumber, parcours Playwright + axe dont l'inscription réelle d'un client.

## Mise à jour d'un environnement local existant
```bash
git pull
cd infra && docker compose up -d --force-recreate keycloak   # charge l'inscription et les libellés
docker compose --profile app up -d --build
```

## Images
`catalog-service`, `order-service`, `stock-service`, `web-frontend` (communauté et éditions inchangés depuis v1.4.0).
