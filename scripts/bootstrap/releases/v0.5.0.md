## Fonctionnel (backlog `docs/backlog.md`)
| User story | Livré | Preuve |
|---|---|---|
| US1 — Catalogue | Liste paginée, fiche, catégories, lecture publique | Tests d'intégration, Cucumber, smoke tests |

## Plateforme
- **Staging Kubernetes** (kind, éphémère) : Kustomize, Gateway API sur Envoy Gateway (TLS cert-manager, JWT, limitation de débit), NetworkPolicies en refus par défaut, pods non root en lecture seule.
- **CD** appelé par la CI : déploiement de l'image du commit (garde-fou), 13 smoke tests, 7 scénarios Cucumber en français, vérification de la supervision, DAST ZAP baseline (0 échec, 3 avertissements à qualifier au J4).
- **Poste local** : docker compose durci (secrets générés, Keycloak avec royaume importé, Prometheus et Grafana provisionnés).
- **Démonstration** : ADR-002 (pas de front-end dans le POC), contrat OpenAPI 3.1, collection Bruno, script de démo.

## Sécurité et qualité
- CodeQL : déclencheur `workflow_run` remplacé par un workflow réutilisable (2 alertes élevées « cache poisoning » corrigées).
- gitleaks : deux faux positifs qualifiés et datés dans `.gitleaksignore`.
- SonarQube Cloud (#32) : en attente du jeton du dépôt, reporté au jalon J4 ; la CI saute l'étape tant que le secret n'existe pas.
