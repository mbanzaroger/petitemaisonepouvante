**Hypothèse** : les outils alimentent les 4 indicateurs et bloquent un build non conforme.

**Critères de succès**
- Un service minimal passe la CI : tests Testcontainers (PostgreSQL réel), couverture JaCoCo remontée dans SonarQube Cloud.
- Trois cas volontairement dégradés font échouer le pipeline : couverture < 80 %, dépendance vulnérable (Trivy), code dupliqué ou smell bloquant (Quality Gate).

**Alternative à comparer** : OWASP Dependency-Check (temps d'exécution, clé NVD, faux positifs) contre Trivy.
