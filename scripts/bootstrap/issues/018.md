**Hypothèse** : les métriques RED et la corrélation des logs sont exploitables pour diagnostiquer la saga et lire un test de charge.

**Critères de succès**
- kube-prometheus-stack (ou Prometheus + Grafana) déployé dans le cluster ; un service Spring Boot scrapé via `/actuator/prometheus`.
- Dashboard RED (débit, erreurs, latence p95) ; alerte sur taux d'erreur.
- `correlationId` propagé dans les logs ; trace distribuée visible (optionnel : OpenTelemetry + Tempo/Jaeger).

**Alternative à comparer** : stack ELK pour les logs centralisés.
